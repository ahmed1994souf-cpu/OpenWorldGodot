# Mystic Throne: Arena (Godot 4)

A fresh, standalone Godot 4 3D mobile prototype stored separately from the existing project.

## Current prototype
- Procedurally built dark fantasy arena with stone pillars and glowing runes.
- Third-person player capsule with a glowing sword.
- Five guards; one stronger purple elite guard.
- Basic enemy chase and melee attacks.
- Player health, enemy count, jump and attack actions.
- On-screen joystick and touch buttons; no external assets required.

## Open on Android
1. Download or clone this repository.
2. In Godot Android Editor, import the folder named MysticThroneMobile (the folder containing project.godot).
3. Open the project and run the main scene.

## Controls
- Left virtual joystick: move.
- JUMP: jump while grounded.
- ATTACK: damage nearby guards in front of the player.

## Important
This is a first playable foundation, not a finished AAA game. It uses procedural placeholder characters and geometry so the project can start without downloading models. Test it in the Godot editor and check the debugger before adding imported characters, animation rigs, larger maps, and save systems.
